# Documentación AppGym

Índice para humanos y agentes de IA. **Empieza aquí** si retomas el proyecto.

| Documento | Para qué |
|-----------|----------|
| [../AGENTS.md](../AGENTS.md) | Reglas de trabajo del agente (no romper flujos) |
| [../MEMORY.md](../MEMORY.md) | Estado vivo, decisiones actuales, backlog |

## Orden recomendado al abrir un chat nuevo

1. `MEMORY.md` — dónde estamos ahora  
2. `AGENTS.md` — límites y convenciones  
3. `docs/HISTORIA.md` — cómo llegamos aquí  
4. `docs/ARQUITECTURA.md` — dónde tocar código  

Tras un cambio de producto o arquitectura: actualizar `MEMORY.md` y, si aplica, `HISTORIA.md`.
